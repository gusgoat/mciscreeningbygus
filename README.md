# แบบประเมินสภาพสมองด้วยตนเอง (Self-Test)

แบบคัดกรองสมอง/ความจำเบื้องต้นแบบทำด้วยตนเอง ระบบตรวจและสรุปผลให้อัตโนมัติ
(ไม่ต้องมีผู้ตรวจ ไม่มีการเก็บข้อมูลออนไลน์ — ทุกอย่างทำงานในเครื่องผู้ใช้)

## วิธีขึ้น GitHub Pages
1. สร้าง repository ใหม่ (เช่น `brain-selftest`) แล้วอัปไฟล์ `index.html` นี้ไว้ที่ราก repo
2. ไปที่ Settings → Pages → Source เลือก `Deploy from a branch` → Branch: `main` / folder `/ (root)` → Save
3. รอสักครู่ จะได้ลิงก์ `https://<username>.github.io/<repo>/` เปิดใช้งานได้ทันที

## หมายเหตุ
- ต้องมีอินเทอร์เน็ตตอนเปิด (โหลด React / Tailwind / jsPDF จาก CDN)
- เป็นเครื่องมือคัดกรองเบื้องต้น ไม่ใช่การวินิจฉัยทางการแพทย์
