# แบบทดสอบสภาพสมองเบื้องต้น (Cognitive Screening)

เครื่องมือคัดกรองภาวะสมองเสื่อม/อัลไซเมอร์เบื้องต้นแบบเชิงโดเมน 30 คะแนน
ครอบคลุม 6 โดเมนปัญญา และแปลผลกลับไปยังตำแหน่งสมองที่น่าจะเกี่ยวข้อง เพื่อช่วยชี้แนวทางการประเมินต่อ

## วิธีใช้งาน
- เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome / Safari / Edge) ได้ทันที
- ต้องต่ออินเทอร์เน็ตตอนเปิด เพราะดึงไลบรารี (React, ไอคอน, Tailwind) จาก CDN
- ผู้ตรวจอ่านคำถามให้ผู้ป่วย แล้วติ๊กคะแนนแต่ละข้อ ระบบสรุปผลและ "แผนที่สมอง" ให้อัตโนมัติ

## ฟีเจอร์
- 12 ข้อ ตามต้นแบบ พร้อมภาพประกอบในตัว (สัตว์ / ใบหน้าอารมณ์ / กล่องสามมิติ)
- ตัวจับเวลาตั้งแต่ให้คำจำ เตือนช่วง 3–5 นาทีที่ควรถามข้อจำคำ (delayed recall)
- อัปโหลดภาพใบหน้าเองสำหรับข้ออ่านอารมณ์ (จดจำไว้ในเบราว์เซอร์)
- สรุปคะแนนรายโดเมน + ไฮไลต์ตำแหน่งสมองที่ควรให้ความสนใจ + พิมพ์ผลได้

## โครงสร้างไฟล์
- `index.html` — เวอร์ชันพร้อมใช้ เปิดด้วยเบราว์เซอร์ได้เลย (สำหรับ GitHub Pages)
- `cognitive-screening-app.jsx` — ซอร์สโค้ด React สำหรับนำไปพัฒนาต่อด้วย Vite

## ข้อจำกัดสำคัญ (โปรดอ่าน)
เครื่องมือนี้เป็นแบบคัดกรองเชิงชี้แนะที่ออกแบบขึ้นเอง **ยังไม่ผ่านการตรวจสอบความตรงและความเที่ยงทางสถิติ**
การแปลผลตำแหน่งสมองเป็นการประมาณเชิงการศึกษา **ไม่ใช่การวินิจฉัย** ควรใช้ร่วมกับประวัติ การตรวจร่างกาย
เครื่องมือมาตรฐาน (เช่น MoCA, MMSE/TMSE) และการประเมินโดยแพทย์ผู้เชี่ยวชาญเสมอ
